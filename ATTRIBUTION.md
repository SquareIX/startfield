# Model Attribution

The hero carousel renders point clouds sampled from the 3D models below.
Only sampled point positions and colors are shipped in `src/assets/points/`
(quantized `.points.b64` files); the original meshes are not redistributed
by this site. All four source models are CC0 (public domain dedication).

## Robot (Ferrum Core slide)

- **Model:** RobotExpressive
- **Author:** Tomás Laulhé (Quaternius), modifications by Don McCurdy
- **License:** CC0 1.0 Universal
- **Source:** https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive

## Flight Helmet (Device Inspector slide)

- **Model:** FlightHelmet, from the glTF Sample Models collection
- **Author:** Donated by Microsoft for glTF testing
- **License:** CC0 1.0 Universal
- **Source:** https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/FlightHelmet

## BoomBox (Network Lab slide)

- **Model:** BoomBox, from the glTF Sample Models collection
- **Author:** Microsoft (copyright waiver)
- **License:** CC0 1.0 Universal
- **Source:** https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/BoomBox

## Power Drill (Automation Kit slide)

- **Model:** Drill 01

- **License:** CC0 1.0 Universal

## Other assets in this repo

`src/assets/` also contains Michiko's own models (`lily.glb`,
`lily-gods.glb`, `lily-researcher.glb`, `perks.glb`) and point clouds
(`angel.ply`, `weapon.ply`) from earlier prototypes. They are not loaded by
the current carousel and are kept for reference.
